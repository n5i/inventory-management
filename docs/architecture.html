Factory Inventory Management System

Architecture overview: a Vue 3 single-page app talking to a FastAPI service backed by in-memory JSON data. No database.

System architecture

Tech stack

Frontend

  • Vue 3 (Composition API)
  • Vite dev server and build
  • vue-router 4
  • axios for HTTP
  • Custom SVG charts, CSS Grid layout

Backend

  • Python 3.11+
  • FastAPI with Pydantic v2 models
  • Uvicorn
  • CORS open to all origins (dev only)

Data

  • JSON files in server/data/
  • Loaded once at startup, held in memory
  • Changes do not persist across restarts
  • generate_data.py regenerates the files

Tooling

  • uv for Python dependencies
  • pytest + FastAPI TestClient (51 tests)
  • scripts/start.sh / stop.sh
  • Claude Code agents, skills, hooks in .claude/

Data flow

  1. The user changes a filter (period, warehouse, category, status). State lives in a module-level singleton in composables/useFilters.js, shared by every view.
  2. getCurrentFilters() maps it to API params: period becomes month (YYYY-MM or a quarter such as Q1-2025), location becomes warehouse. The value all means no filter.
  3. api.js sends the request with axios. Each view fetches its own data; there is no global store.
  4. The FastAPI route applies apply_filters and filter_by_month to the in-memory lists, then validates the result against a Pydantic response_model.
  5. The view keeps raw data in refs and derives chart and table values with computed properties.
  6. Currency is converted only at display time (utils/currency.js): the API always returns USD, and the Japanese locale shows JPY at a fixed 150 rate.

Cross-cutting concerns

Internationalization

useI18n serves en and ja strings via dotted keys with English fallback. The locale is saved in localStorage and also selects the currency.

Authentication

None. useAuth supplies a mock user on the client only.

Persistence

None. Data is read from JSON at startup and never written back.

Known gaps

Missing backend routes. api.js calls /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders, but main.py defines no such routes. Only the PurchaseOrder models and sample data exist.

Unrouted view. views/Backlog.vue exists, but client/src/main.js does not register a route for it.
